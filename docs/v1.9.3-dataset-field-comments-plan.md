# v1.9.3 数据集字段注释(field comments):摄入捕获 + 暴露 + 编辑

> 状态:实施中(2026-07-24)。方案已核实 + 用户批准。

## Context

结构化数据集(CSV/Parquet/DB)摄入到 Lance 后**丢失列注释**;console 的 dataset-detail Schema 面板只显示「字段名 + 类型」,看不到业务含义。目标:摄入时按格式**捕获**列注释写入 Arrow field metadata(随 Lance schema 落盘,与数据同生命周期,**不依赖 Gravitino**);`SchemaResponse` 暴露;console 展示 + 手填编辑。

### 已核实的三个关键事实(决定方案)

1. **Daft `read_parquet().to_arrow()` 会丢弃 PyArrow field metadata** → Parquet 注释必须**直接用 PyArrow**(`pq.ParquetFile(path).schema_arrow`)读,不能依赖 Daft 重建的 schema。
2. **Lance 7.0.0 有 `update_field_metadata({...}, replace=False)`**(原位改字段 metadata,不重写数据)→ 注释端点 + DB 写回都用它,廉价。
3. **`Lake.open_dataset()` 返回的 `LanceTable` 不代理 `update_field_metadata`** → 需经 `lance.dataset(dataset_uri)` 原始句柄;`StorageManager.dataset_uri(name)` 已有(`storage.py:242`)。

## Storage 共享原语(一处实现,DB 写回 + 注释端点共用)

**`arrow_lake/ingest/storage.py`** — `LanceStorageManager` 加方法:
```python
def update_field_comments(self, name: str, comments: dict[str, str]) -> None:
    """原位更新字段 comment 元数据(增量,不重写数据)。"""
    import lance
    ds = lance.dataset(self.dataset_uri(name), storage_options=self._storage_options)
    payload = {c: {"comment": v} for c, v in comments.items() if c}
    if payload:
        ds.update_field_metadata(payload, replace=False)
```
- `self._storage_options` 已存在(`storage.py:72`)。

**`arrow_lake/_lake_admin.py`** — `Lake` facade 加薄包装(供 router 用,与 `open_dataset` 同 mixin,L171 附近):
```python
def update_field_comments(self, name, comments):
    self._get_storage().update_field_comments(name, comments)
```

## Layer 1 — 摄入捕获(按格式)

### 1a. 新模块 `arrow_lake/ingest/field_comments.py`(纯函数,~70 行)
- `extract_parquet_comments(path) -> dict[str,str]`:`pq.ParquetFile(path).schema_arrow`,逐 field 取 `field.metadata` 中 `b"comment"`(Hive/Spark)/`b"description"`,utf-8 decode + strip。
- `extract_csv_sidecar_comments(path) -> dict[str,str]`:stem=`Path(path).stem`,dir=父目录。先找 `{stem}.columns.json`(`{col: comment}`);再找 `{stem}.meta.yaml`(`yaml.safe_load`,支持 `columns: {col: comment}`)。best-effort,异常返 `{}`。
- `attach_field_comments(table: pa.Table, comments: dict[str,str]) -> pa.Table`:重建 schema 给命中的 field 挂 `b"comment"` metadata(用 `pa.Table.from_arrays(table.columns, schema=new_schema)`,**不能用 `cast`**)。
- `capture_for_file(source_path: str, file_type: str, table: pa.Table) -> pa.Table`:按 file_type 派发(parquet/csv),整体 try/except → 失败返原 table(永不阻塞摄入)。

### 1b. `arrow_lake/ingest/ingestor.py` `_write_table`(L80)
在 quality_gate 之后、create/append 之前,插入(单一干净拦截点,覆盖 `ingest_files` 主路径):
```python
try:
    ft = self._detect_file_type(source_path)
    from arrow_lake.ingest.field_comments import capture_for_file
    table = capture_for_file(source_path, ft, table)
except Exception:
    logger.debug("field_comment_capture_skipped", path=source_path, exc_info=True)
```

### 1c. DB(MySQL/PG)— `arrow_lake/ingest/connectors_sql.py`
`SqlConnector` 加 `fetch_column_comments(sql) -> dict[str,str]`:
- 方言 = `urlparse(self._conn).scheme`(`mysql*` → MySQL;`postgres*` → PG;其它返 `{}`)。
- 抽 SQL 首个表:`re.search(r"\bFROM\s+([\w.]+)", sql, re.I)`;按 `.` 拆 schema/table。
- 经 `sqlalchemy.create_engine(self._conn).connect()`(lazy import,缺失/异常 → `{}`)执行:
  - MySQL:`SELECT column_name, column_comment FROM information_schema.columns WHERE table_name=:t [AND table_schema=:s]`
  - PG:`SELECT a.attname, col_description(a.attrelid, a.attnum) FROM pg_attribute a JOIN pg_class c ON a.attrelid=c.oid WHERE c.relname=:t AND a.attnum>0 AND NOT a.attisdropped`
- 只收非空 comment → `{col: comment}`。

**`arrow_lake/ingest/_ingest_sources.py` `ingest_sql`**(L42-47 之后):
```python
self._manager.write_lance_from_dataframe(dataset_name, df, mode="create")
try:
    comments = connector.fetch_column_comments(sql)
    if comments:
        self._manager.update_field_comments(dataset_name, comments)
except Exception:
    pass  # best-effort
```
> `ingest_batch` 亦走 `write_lance_from_dataframe`,本批不为 batch 加注释捕获(文件类 batch 已有 `_write_table` 路径覆盖;batch 是次要路径)。

## 风险 / 注意
- Daft 丢 metadata 已用「PyArrow 直读」绕开,不依赖 Daft。
- `attach_field_comments` 必须 `from_arrays` 重建 schema(`cast` 只改类型不改 metadata)。
- 字段 metadata 是 `dict[bytes,bytes]`,读写注意 encode/decode + `or {}` 防 None。
- `update_field_metadata` 是 Lance 7.0.0 API;`replace_field_metadata` 已 deprecated,不用。
- 捕获全程 best-effort(try/except + debug log),**绝不阻塞摄入**。
