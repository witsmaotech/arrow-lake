REST API 使用指南

FastAPI 内置服务覆盖摄取、检索、RAG、知识图谱、治理等全部能力。支持 API Key 与 JWT + RBAC 双模认证，统一错误信封与链路追踪。

难度 · 中级 耗时 · 20 分钟 依赖 · arrow-lake[api] · curl/httpx

Arrow Lake 内置 FastAPI REST 服务，提供数据摄取、向量搜索、RAG 问答、知识图谱管理等全部功能的 HTTP 接口。支持 API Key 认证和 JWT + RBAC 双模式。前置准备：pip install arrow-lake[api]。

1启动服务器

启动后访问 Swagger UI：http://localhost:8000/docs，ReDoc：http://localhost:8000/redoc。

2API Key 认证

在配置中设置 api.api_key 后，所有非文档端点需要通过 X-API-Key 请求头认证。

未携带 API Key 时返回 401：{"detail": "Missing or invalid API key"}

3JWT 认证与 RBAC

认证模式通过 auth.auth_mode 配置，可选 api_key、jwt 或 both。角色层级为 ADMIN > EDITOR > VIEWER，高级角色继承低级角色全部权限。

角色说明权限范围
ADMIN管理员全部操作，包括图谱构建、数据集删除
EDITOR编辑者数据摄取、搜索、Gremlin 查询
VIEWER查看者只读搜索、RAG 问答

JWT 配置参考

配置项默认值说明
auth.auth_mode"api_key"认证模式：api_key / jwt / both
auth.jwt_secret_key""JWT 签名密钥（v1.5.2 起为空则阻止启动）
auth.jwt_algorithm"HS256"签名算法
auth.jwt_access_token_minutes30Access Token 有效期（分钟）
auth.jwt_refresh_token_days7Refresh Token 有效期（天）
auth.jwt_issuer"arrow-lake"JWT issuer 声明

7错误响应格式

所有错误响应使用统一的 JSON 信封：

字段类型说明
successbool始终为 false
errorstr错误码（机器可读）
messagestr人类可读的错误描述
contextobject可选附加上下文

常见 HTTP 状态码：400 参数校验失败、401 未认证、403 权限不足、404 资源不存在、413 请求体过大、429 速率限制、500 服务内部异常。

8高级配置

每个请求自动生成 X-Request-ID 头用于链路追踪；客户端可自行传入（设置 auto_generate_request_id: false 关闭自动生成）。

9RBAC 角色矩阵

超过 30 个 API 端点通过 require_role() 依赖项执行基于角色的访问控制。PermissionChecker 支持按数据集的 ACL 覆盖——ADMIN 可向 VIEWER 授予特定数据集的写入权限而无需更改其全局角色。

能力类别VIEWEREDITORADMIN
搜索与查询search/*（继承 VIEWER）（继承所有）
RAG / GraphRAGrag/query/*、graphrag（继承 VIEWER）（继承所有）
数据摄取-ingest/*、datasets DELETE（继承所有）
向量嵌入-embedding/*（继承所有）
质量与去重-quality/*、dedup/*（继承所有）
血缘与审计-lineage 写入audit 导出
导出-export/*（继承所有）
备份--backup/*
知识图谱构建-kg/querykg/build、admin/*
数据集 ACL 管理--授予 / 撤销数据集访问权限

14v1.5.2 安全加固

v1.5.2 应用了以下安全加固措施，自动生效，无需配置更改。

领域加固内容
JWT空 jwt_secret_key 现在会阻止服务器启动
Kerberos认证提供程序中的命令注入漏洞已消除
SQL所有面向用户的查询均使用参数化执行
Redis移除默认密码；必须显式配置
网络所有端口默认绑定到 127.0.0.1
SSRFingest_http 和预签名端点增加 URL 校验
Admin角色枚举取代基于字符串的管理员绕过
令牌Refresh Token 轮换，支持撤销
Gremlinkg_query 端点增加输入净化
推荐

联调优先用 http://127.0.0.1:8000/console/*.html（同源 API 无 CORS）。Swagger 文档在 /docs，交互式调试最便捷。
