arrow-lake 是覆盖数据湖全生命周期的命令行工具：摄取、索引、搜索、SQL 分析、RAG、知识图谱、质量、备份、审计、血缘、生命周期。本教程所有实战场景使用 examples/data/ 目录的真实示例数据，可直接运行。

14存储配置：本地与 S3/MinIO

Arrow Lake 支持将数据存储在 S3 或 MinIO 上，CLI 命令不需要改变——只需通过配置文件或环境变量指定 S3 连接信息。--base-uri 在 S3 模式下是桶内前缀，不是完整路径。

配置优先级

YAML 配置文件（最高） > 环境变量（ARROW_LAKE__*） > .env 文件 > 代码默认值。系统检测到 s3_access_key 为空或以 < 开头时，会静默回退为本地存储。

17常见问题

Q：--base-uri 能直接写 s3://bucket/prefix 吗？

不能。--base-uri 始终是本地路径或桶内前缀。S3 连接信息通过 --config 或环境变量单独提供，系统内部拼接为 s3://{bucket}/{base_uri}/{dataset}.lance。

Q：配置了 S3 但忘了填密钥会怎样？

会静默回退为本地存储。系统检测到 s3_access_key 为空或以 < 开头时，不传递 S3 配置给 Lance 引擎。

Q：很多参数默认值显示"无（使用配置默认值）"是什么意思？

CLI 的 --column、--metric、--strategy 等参数默认值为 None，此时回退到 YAML 配置或 arrow-lake config show 的默认值。如需覆盖，通过命令行参数显式指定。

Q：切换存储后端需要改 CLI 命令吗？

不需要。所有 CLI 命令与存储后端无关，切换只需改配置。
