## P0-6 masking 治理

### policy 层暴露 function
- `arrow_lake/quality/gravitino_policies.py:74` 加 `function: Literal["redact","hash","partial","nullify"]="redact"`;line 87 `"redact"`→`function`。默认 redact 零破坏。
- `arrow_lake/api/routers/gravitino.py:288-299` body 加 `function = body.get("function","redact")` 透传。

### HMAC fail-fast + opt-in
- `arrow_lake/quality/masking_engine.py:__init__(43-52)`:缺 key 且 `ARROW_LAKE__MASKING__ALLOW_MISSING_KEY != "1"` → `raise RuntimeError`;否则 warning。
- `_mask_column` hash 分支:opt-in + 用 hash + 无 key → raise `MaskingKeyMissing`(不再静默 fallback nullify)。
- deploy 配 `ARROW_LAKE__MASKING__HMAC_KEY` + 文档说明 opt-in。

### audit(复用 Lance)
- `create_masking_policy` 端点成功后,router 层调 `lake.audit_record(event_type="masking_policy_created", dataset_name=None, actor=<auth>, payload={policy_name, columns, function})`。复用 `_lake_audit.py:28` + `/api/v1/audit/query`。

### 预览端点 + 前端
- 新 `POST /api/v1/datasets/{name}/quality/mask-preview`(`quality.py`,EDITOR+):body `{columns, function}`,读前 5 行,对每列调 `MaskingEngine._mask_column`(复用 `app.state` engine),返 `{column:{before,after}}`。
- `console/governance.html` masking 表单:加 `<select id="mkFn">` 4 选 1;payload 加 function;加预览按钮 → 调 mask-preview;策略列表(line 214)显示 function。

### 测试
- create_masking_policy function 透传(line 87 不再恒 redact)。
- HMAC:缺 key + 非 opt-in → raise;opt-in → 不 raise。
- mask-preview 端点(4 function 各一例)。
- audit:create policy 后 `audit_query` 能查到事件。
