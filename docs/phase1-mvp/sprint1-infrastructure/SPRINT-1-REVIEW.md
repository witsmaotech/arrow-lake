## 🔧 问题与解决方案

### 遇到的主要问题

#### 1. Docker 模块命名冲突
**问题**: 目录名与 Python 包名冲突导致导入失败
**解决**: 重命名目录 (lancedb → lancedb_service)
**影响**: 延迟 30 分钟
**预防**: 统一命名规范文档

#### 2. 端口冲突
**问题**: 端口 5432, 3000, 6379 被占用
**解决**: 映射到 15432, 13000, 16379
**影响**: 延迟 15 分钟
**预防**: 端口使用规范文档

#### 3. Daft API 变更
**问题**: API 不兼容 (select(), pow() 语法变更)
**解决**: 查阅文档，更新语法
**影响**: 延迟 1 小时
**预防**: 版本锁定和变更日志

#### 4. LanceDB 索引 API
**问题**: create_index() 参数不明确
**解决**: 查阅源码，找到正确 API (metric + vector_column_name)
**影响**: 延迟 2 小时
**预防**: API 文档完善

#### 5. MinIO 配置
**问题**: 新版本绑定 127.0.0.1 导致外部无法访问
**解决**: 添加 --address ":9000" 参数
**影响**: 延迟 30 分钟
**预防**: 版本升级测试

### 问题分类

| 类型 | 数量 | 占比 |
|------|------|------|
| **配置问题** | 3 | 60% |
| **API 兼容性** | 2 | 40% |

**经验**: 大部分问题可通过预先测试和文档避免。
