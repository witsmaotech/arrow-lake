← 返回模板列表

0 模板定义

编辑模板后「保存」(PUT /{name}),反复迭代 guideline / 字段枚举 —— 质量瓶颈在模板不在模型。

1 ✨ 生成场景文档

LLM 读模板 → 生成 ~2000 字场景文档,强制覆盖每种实体 / 关系类型(每种实体 ≥2 例)。可编辑后用于建图。

2 生成图谱(真 HugeGraph)

用上方文档 ingest+index 建临时数据集 → kg_build(template=name) → 可视化。build 分钟级,异步轮询。

3 RAG 问答测试(GraphRAG)

复用 POST /api/v1/rag/query {use_kg:true},在临时数据集上问答,验证模板是否支持有意义检索。
—

4 清理临时数据

删除验证产生的临时数据集及其 kg 图(DELETE /quality/{temp_dataset}),释放空间。隔离的 KA 文件(/data/lake/template-quality-ka/)一并删除。

5 保存验证结果 / 查看历史

把本次验证(文档 + 实体/关系计数 + 图快照 + RAG 问答)持久化,清理后仍可在历史里回看(图快照重放)。每模板独立历史。
