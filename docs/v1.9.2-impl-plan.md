## §1. 全局架构与约束

- **console 模式**:零 npm 依赖、零构建(浏览器原生 ES module)。每页 `<script type="module"> import { request } from "./src/api.js"` + `const { renderShell, icon } = window; renderShell({active, crumb})` + `assets/{tokens,app,console}.css`。鉴权走 `api.js` 双层(Bearer + X-API-Key,auth_mode=BOTH),401 auto-refresh。role 从 JWT payload 解(`localStorage.al_access` base64 → `role`),写操作按钮按 role 显隐。
- **后端契约**:Role 分级 VIEWER/EDITOR/ADMIN;异步任务返 202 + task_id;admin 端点 prefix `/api/v1/admin`;审计事件经 `_audit_trail`(HMAC 签名)落 turso system_db(v1.9.0 接管 RBAC/身份/personal_token)。
- **部署**:`docker compose --project-directory deploy -p arrow-lake -f deploy/docker-compose.prod_minimal.yml`。api 容器 `read_only: true` → **改后端源码必须 rebuild 镜像**;**联调首选 dev override**(`-f deploy/docker-compose.dev.override.yml up -d --force-recreate api`,挂源码 + uvicorn --reload,改 Python 秒级热重载)。
- **验证**:playwright chromium-1217(`~/.cache/ms-playwright/chromium-1217/chrome-linux64/chrome`)+ `.venv/bin/python3`。前端:0 console error / 0 横向溢出(`scrollWidth<=clientWidth`)/ 真数据。后端:`pytest -q --tb=line --no-header -x`。
- **trunk-based**:直接提交 master。conventional commits + `Co-Authored-By: Claude <noreply@anthropic.com>`。
