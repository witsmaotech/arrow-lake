第 11 章 · 质量

数据质量与去重

使用 Arrow Lake 的质量过滤和内容去重管线，确保入库数据的完整性和唯一性。覆盖精确 / 感知 / MinHash / NeMo Curator 四级去重、声明式规则引擎、死信队列与 Gravitino 治理。

难度 · 中级 耗时 · 15 分钟 依赖 · arrow-lake[dedup] · imagehash（可选）

数据质量是检索与分析可信度的基石。Arrow Lake 把质量过滤、多策略去重、声明式规则、死信队列、质量画像、治理策略收敛到统一的 facade 与 REST 端点之下。

1质量过滤器

quality_filter() 对数据集运行所有已注册的质量过滤器，返回一份聚合报告。

参数说明

参数类型默认值说明
dataset_namestr(必填)数据集名称
active_filtersstr配置值逗号分隔的过滤器名，空串使用全部
modestr"all"all = AND（全部通过），any = OR

QualityReport 是 frozen dataclass，含 total / passed / rejected / filter_results / schema_rejected / duration_seconds 字段。

2内置过滤器

两个内置过滤器可通过 configs/dev.yaml 的 quality 段调整阈值。运行前会先做 schema 验证：lenient（默认，丢弃未知列）或 strict（拒绝未知列与类型不匹配）。

TextLengthFilter

过滤文本长度不满足要求的行，要求数据集含 text_content 列。

ImageResolutionFilter

过滤图片分辨率低于阈值的行，要求列名为 image_data 且值为可解码字节。

3精确去重（SHA-256）

deduplicate() 默认使用 SHA-256 哈希进行精确去重，适用于文本和二进制数据。

action 值说明
"flag"保留所有行，新增 is_duplicate 布尔列标记重复
"remove"直接从结果表移除重复行，返回去重后的表

4感知去重（pHash）

对于图片数据集，使用感知哈希（pHash）检测视觉相似但非完全相同的图片。底层用 imagehash 计算 phash，再比较 Hamming 距离。

pHash 阈值参考

阈值语义
0完全相同的图片
5轻微裁剪 / 压缩变体
10（默认）明显缩放 / 水印 / 颜色偏移
20宽松模式，允许较大视觉差异
依赖说明

感知去重需要 imagehash 库，通过 pip install arrow-lake[dedup] 安装。

5MinHash 近似去重（CPU datasketch）

除精确 SHA-256 和感知 pHash 外，ContentDeduplicator 还内置 MinHash LSH 近似去重（quality/dedup.py），基于 CPU 版 datasketch，用于检测语义近重复文本（改写、少量编辑的变体），无需 GPU。

陷阱：YAML 不接受 minhash

QualityConfig.dedup_strategy 的 validator 只允许 exact / perceptual / both，写 minhash 会触发 ValidationError。MinHash 只能编程式调用 ContentDeduplicator(strategy="minhash", ...)，不能通过 dedup_strategy: minhash 配置。大规模语料（>1M 行）需 GPU 时用 NeMo Curator。

6NeMo Curator 集成（GPU 加速 MinHash LSH）

对于大规模文本去重，Arrow Lake 支持通过 NeMo Curator 进行 GPU 加速的 MinHash LSH 近似去重（pip install arrow-lake[nemo-curator]）。

7死信队列

质量过滤和 schema 验证中被拒绝的行会进入死信队列（Dead Letter Queue），支持重试、解决和清理。状态流转：pending → retrying → pending（失败）/ resolved；也可直接 pending → permanent。

8质量规则引擎（v1.4.0）

声明式 QualityRuleEngine 用可配置规则替代硬编码过滤器，支持从 JSON、YAML 或 REST API 加载。

Check参数说明
lengthmin, max字符串长度范围
rangemin, max数值范围
regexpattern, invert正则匹配（invert=True 匹配不满足的）
duplicate—精确哈希重复检测
Actionevaluate() 效果apply() 效果
reject / remove报告违规数量移除违规行
flag报告违规数量保留行（仅作标记）

9质量画像与评分

QualityProfiler（quality/profiler.py）对数据集做整体质量画像，输出 DatasetQualityProfile，含 overall_quality_score（0.0–1.0）和各维度统计（空值率、基数、分布等）。

10质量 REST API 全景

routers/quality.py 暴露的端点（前缀 /api/v1/datasets/{name}/quality）：

方法端点说明
POST/quality/filter运行质量过滤器，返回聚合报告
GET/quality/report获取上一次质量过滤报告
POST/quality/deduplicate对数据集去重（exact/perceptual/both）
POST/quality/rules应用声明式规则引擎
GET/quality/profile质量画像与评分
POST/quality/llm_label / /extractLLM 富化：打标签 / 结构化抽取（异步 202）
POST/quality/mask-preview预览脱敏效果（function/columns）

llm_label 与 extract 走 fire-and-forget 异步任务（status_code=202），立即返回 task_id，通过 GET /api/v1/tasks/{task_id}/status 轮询结果。

11行 / 列级访问控制

行级和列级 ACL 限制每个角色在查询和搜索结果中能看到的数据。ACL 过滤自动应用于所有查询（OLAP / 元数据 / Daft）和搜索（向量 / 全文 / 混合 / 分面 / 集成）端点——客户端无需改动。

工作原理

列裁剪：不可见列在结果序列化前被移除；行过滤：用 column op value 表达式（==、!=、<、<=、>、>=）过滤；Admin 绕过：admin 角色始终能看到所有数据；无 ACL = 不过滤：未配置时结果原样返回。

12Gravitino 标签与策略（v1.4.1）

Arrow Lake 集成 Apache Gravitino 实现元数据驱动的数据治理。GravitinoTagService 和 GravitinoPolicyService 提供数据分类、保留管理和列脱敏功能。当 Gravitino 不可用时优雅降级（返回空列表而非报错）。

数据分类（GravitinoTagService）

常量值用途
SENSITIVE"sensitive"通用敏感数据标记
PII"pii"个人身份信息
FINANCIAL"financial"金融或支付相关数据
EXPIRES_30D"expires:30d"30 天后应清除的数据

保留策略与脱敏（GravitinoPolicyService）

标签和策略也可通过 /api/v1/metadata/* REST 端点管理（详见 REST API 章节）。当 gravitino.enabled 为 false（默认）时，这些端点返回 503，治理服务静默完成不连接，质量过滤 / 去重 / ACL 不受影响。

13数据准备：清洗与 LLM 富化

结构化清洗 POST /clean

把声明式清洗步骤（DuckDB 语义）编译成 SQL，再经 restore_dataset 写回 Lance，支持按列链式算子。

字段注释（v1.9.3）

ingest/field_comments.py 支持给数据集字段加人类可读注释（PyArrow 直读 parquet/CSV sidecar，写入 Lance schema comment 元数据）。摄入时由 _write_table 钩子自动捕获，后续 GET /schema 会回显。

14质量配置参考与最佳实践

何时用哪种去重策略

场景推荐策略说明
文章 / 新闻 / 代码exact相同内容产生相同 SHA-256，精确高效
产品图片去重perceptual（threshold 5-10）过滤不同尺寸 / 压缩率的同一商品图
社交媒体图片perceptual（threshold 10-15）允许滤镜 / 裁剪差异
中等文本近重复（改写 / 少量编辑）minhash（CPU，编程式）检测 Jaccard 相似度近重复，无需 GPU
大规模文本语料（>1M 行）NeMoDeduplicator（GPU）MinHash LSH 近似去重，速度远超精确匹配
混合数据集（文本 + 图片）both先精确去重再感知去重，两阶段流水线

典型数据质量管线

性能提示

质量过滤和去重对数据集进行全表扫描，建议在非高峰期运行；>100 万行启用 NeMo Curator GPU 加速；perceptual 策略需解码图片字节计算 pHash，CPU 消耗较大；设置 text_max_chars 可提前过滤超长文本。
