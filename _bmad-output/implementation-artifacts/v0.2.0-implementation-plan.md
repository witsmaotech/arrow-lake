## Context

Arrow Lake v0.1.0 是一个 Python SDK（`Lake` 类），提供完整的多模态数据湖库能力（摄入、搜索、查询、导出、质量、血缘、审计），但没有 HTTP API。v0.2.0 的目标是添加 FastAPI REST 层，将 Lake SDK 暴露为可部署的数据服务。

**设计原则**：薄 API 层，每个 endpoint 1:1 映射到 `Lake` SDK 方法，不复制业务逻辑。

**参考文档**：
- 设计规格：`_bmad-output/implementation-artifacts/v0.2.0-roadmap-design.md`

### 修改文件

- **`arrow_lake/config.py`** — 新增 `ApiConfig(BaseModel)` 字段：
  ```python
  class ApiConfig(BaseModel):
      enabled: bool = False
      host: str = "0.0.0.0"
      port: int = 8000
      api_key: str = ""                    # 空=禁用
      api_key_header: str = "X-API-Key"
      cors_origins: list[str] = ["*"]
      arrow_ipc_threshold_bytes: int = 10240  # 10KB
      request_timeout_seconds: float = 300.0
      max_request_size_bytes: int = 100 * 1024 * 1024
  ```
  `ArrowLakeConfig` 增加 `api: ApiConfig = ApiConfig()`，`from_yaml()` 的构造函数参数同步增加。

- **`pyproject.toml`** — 依赖增加 `fastapi>=0.115`, `uvicorn[standard]>=0.34`, `python-multipart>=0.0.18`

- **`arrow_lake/server.py`** — 顶部加 `DeprecationWarning`，保留向后兼容

### 关键实现

**ErrorCode → HTTP Status 映射**（`errors.py`）：
```
VALIDATION_* / QUERY_SYNTAX_ERROR / INGEST_SCHEMA_MISMATCH  → 400
CATALOG_DATASET_NOT_FOUND / QUERY_INDEX_NOT_FOUND           → 404
QUERY_TIMEOUT                                               → 504
STORAGE_* / HTTP_* / EMBEDDING_*                            → 502
RAY_RUNTIME_*                                               → 503
其余                                                       → 500
```

**Arrow IPC 序列化**（`models/common.py`）：
```python
def arrow_table_to_ipc_base64(table: pa.Table) -> str:
    sink = pa.BufferOutputStream()
    writer = pa.ipc.new_stream(sink, table.schema)
    writer.write_table(table)
    writer.close()
    return base64.b64encode(sink.getvalue().to_pybytes()).decode()
```

### 端点 → SDK 映射

| 端点 | SDK 方法 |
|------|---------|
| `POST /api/v1/datasets/{name}/ingest` | `lake.ingest(name, file_paths)` → `IngestionReport` |

| `GET /api/v1/datasets` | `lake.catalog()` → `CatalogResult` |
| `GET /api/v1/datasets/{name}` | `lake.catalog()` + 过滤 |
| `DELETE /api/v1/datasets/{name}` | `lake.delete_dataset(name)` |

### 新建文件

|------|------|

### 端点 → SDK 映射

| 端点 | SDK 方法 |
|------|---------|
| `POST .../search/vector` | `lake.search()` |
| `POST .../search/fts` | `lake.text_search()` |

```
Sprint 1 (基础框架)
    ├── Sprint 2 (Dataset) ──→ Sprint 3 (Search) ──→ Sprint 4 (Query+Export)
    ├── Sprint 5 (Quality+Embedding)
    └── Sprint 6 (Lineage+Audit)
                                        ↓
                              Sprint 7 (部署+CLI)
                                        ↓
                              Sprint 8 (性能+发布)
```

Sprint 2/5/6 可在 Sprint 1 完成后并行开发。Sprint 3 依赖 Sprint 2（dataset 存在才能搜索）。Sprint 7/8 依赖所有功能 Sprint 完成。
