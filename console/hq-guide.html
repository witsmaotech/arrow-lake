一条数据集从普通表格到高质量发布物的标准操作顺序。前置:标注员账号已在 Label Studio(127.0.0.1:8085)就位。
① 契约   本体与语义 → 建模工作台:设计对象类/标识/属性 → 保存「数据契约」
② 标注   本页第②步 → 标注生产线:新建项目(选数据集+模板)→ 采样派发
         → 标注员打开 Label Studio 标注(相关性三分类 + 实体/关系)
         → 回收(30s 自动 / 手动)→ ADL 真值落库,看板显示 approved/κ
③ 评估   本页第③步「立即评估」→ 五维得分;relevance 低时先点质量报告页
         「相关性回路」补标 → 人工标完再评估(Annotation 权重最高)
④ 发布   本页第④步 → 发布管理:填 changelog 发布(门禁=报告准入+否决
         +拒绝劣化+漂移;被拒会显示原因,force 需理由留审计)
⑤ 语料   本页第⑤步:填脱敏规则(L2 泛化,如手机号→[手机号])→ 四形态
         导出(sft/pretrain/rlhf/golden),golden 可入 tests/benchmark/golden
⑥ 飞轮   研判台:勾「记录研判」对对象研判(EDITOR+)→ 本页第⑥步看低置信
         → 质量报告「飞轮回流」auto 入队 → 标注补标 → 回到③,闭环
