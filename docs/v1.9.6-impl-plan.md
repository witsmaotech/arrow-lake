## 批 1 ｜ RAG 质量闭环(P0-1 + P0-2 + P1-9)

### P0-1 RAG 防幻觉(faithfulness verify)

**目标**:生成后校验答案每句是否被 context 支撑,标 unsupported,返 support_ratio。

**改动**:
1. **新 `arrow_lake/rag/verifier.py`**:
   - `VerificationResult(dataclass): support_ratio: float, sentences: list[{text, label, src_chunk_idx}]`
   - `class FaithfulnessVerifier`:
     - 轻量版 `verify_embedding(answer, window, encoder)`:正则提 `[n]` 校验编号有效 + 答案句 embedding vs 命中 chunk cosine(阈值 0.6 → unsupported),复用 `extract_llm` 的 encoder。
     - LLM judge 版 `verify_llm(answer, context, provider)`:单次调用 faithfulness prompt(逐句 vs context,输出 JSON `{sentences:[{text,label}]}`)。
2. **`arrow_lake/rag/pipeline.py:333`**(`generate` 后,`RAGResponse` 前):
   - 加 `if self._config.enable_verification: verification = await self._verify(answer, window)`。
   - `_verify` 委托 `FaithfulnessVerifier`(按 config 选 embedding/llm)。
3. **`arrow_lake/rag/pipeline.py:56` `RAGResponse`**:加 `verification: VerificationResult | None = None`。
4. **`arrow_lake/config/rag.py`**:加 `enable_verification: bool = False` + `verification_mode: Literal["embedding","llm"]="embedding"` + `verification_threshold: float = 0.6`。
5. **`arrow_lake/api/models/rag.py` `RAGQueryResponse`**:加 `verification` 字段透传。

**步骤**:
1. 写 verifier.py(轻量 embedding 版先)
2. pipeline 接入 + config 开关
3. 测试:`tests/unit/rag/test_verifier.py`(mock encoder,验 support_ratio + unsupported 标注)

**验证**:同题开/关 verification,看 support_ratio + 前端 unsupported 句高亮。

**风险**:LLM judge 版多一次 LLM 调用(延迟 + 成本),默认 embedding 版。

**工作量**:M(轻量 S,LLM M)| **代码**:`rag/verifier.py`(新)/ `pipeline.py:333,56` / `config/rag.py`

### P0-2 Reranker 默认 cross-encoder + warmup

**目标**:reranker 从 ollama binary → cross-encoder(bge-reranker-v2-m3 连续分),排序质量提升。

**改动**:
1. **`arrow_lake/config/rag.py:82`**:`reranker: str = "cross-encoder"`(默认切)。
2. **`arrow_lake/config/rag.py`**:加 `reranker_device: str = "auto"` + `reranker_warmup_on_init: bool = True`。
3. **`arrow_lake/rag/reranker.py:67` `CrossEncoderReranker`**:
   - `__init__` 加 `device: str = "auto"` → `_load_model` 用 `CrossEncoder(model, device=device|"cuda" if available)`。
   - 加 `warmup()`:`self._load_model(); self._model.predict([("warmup","warmup")])`。
4. **`arrow_lake/_lake_rag.py:112` `_build_reranker`**:构造后 `if rag_cfg.reranker_warmup_on_init: reranker.warmup()`。
5. **`deploy/Dockerfile` / 部署文档**:预下载 `hugging-cli download BAAI/bge-reranker-v2-m3`(HF_HOME 卷,避免运行时下)。

**步骤**:
1. config 默认切 + device/warmup 字段
2. CrossEncoderReranker device + warmup
3. _build_reranker warmup 调用
4. 测试:`tests/unit/rag/test_reranker.py`(验 cross-encoder 连续分 + warmup)

**验证**:同题 cross-encoder vs ollama,看 rerank_score 连续 + 排序变化。

**风险**:bge-reranker-v2-m3 2.2GB,首加载慢(warmup 缓解);HF 离线需预下载。

**工作量**:S | **代码**:`config/rag.py:82` / `reranker.py:67` / `_lake_rag.py:112`
