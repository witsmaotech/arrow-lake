## 🔧 技术方案

### 方案 1: Gunicorn 多 Worker (推荐)

#### 优点
- ✅ 成熟稳定
- ✅ 配置简单
- ✅ 自动 worker 管理
- ✅ 支持 gevent/eventlet

#### 实现
```bash
# docker-compose.yml
lancedb-service:
  command: gunicorn -w 4 -k uvicorn lancedb_service:app
  environment:
    - WORKERS=4
    - TIMEOUT=120
```

**预期 QPS**: 283.21 × 4 = 1133 ✅

### 方案 2: 自定义 Worker Pool

#### 优点
- ✅ 更灵活的控制
- ✅ 可自定义负载均衡
- ✅ 更细粒度的监控

#### 实现
```python
# worker_pool.py
from multiprocessing import Pool
import lancedb

def worker_init():
    global db
    db = lancedb.connect("/data/lancedb")

def worker_search(query):
    return db.table.search(query).limit(10).to_pandas()

class LanceDBWorkerPool:
    def __init__(self, num_workers=4):
        self.pool = Pool(num_workers, initializer=worker_init)

    def search(self, queries):
        return self.pool.map(worker_search, queries)
```

**预期 QPS**: 283.21 × 4 = 1133 ✅
