REST 实战配方

五个端到端场景把多个端点串成完整工作流：文档知识库 + RAG、多模态以图搜图 + 导出、治理闭环、OLAP + 清洗 + 血缘、混合检索 + GraphRAG。

难度 · 进阶 耗时 · 15 分钟 依赖 · 运行中的 API（127.0.0.1:8000）

面向真实 REST API 的端到端实战场景。每个食谱把多个端点串成一个完整工作流——本章讲的是把事做成。所有示例用 curl 访问 http://127.0.0.1:8000。先设好 base URL 与 key：

1场景一：文档知识库 + 防幻觉 RAG

摄入 PDF/文档，让管线自动建向量索引，再提问。

字段名注意

请求体用 question / dataset_name（不是 query/dataset）；use_kg 默认 true，GraphRAG 在 hugegraph 启用时自动注入，失败优雅降级。

2场景二：多模态以图搜图 + 导出

建图像数据集，按图搜索，导出命中结果。

3场景三：治理闭环 —— 脱敏 + 血缘 + 审计

脱敏 PII、预览规则、追溯血缘、审计策略变更。

4场景四：OLAP 分析 + 清洗 + 血缘

跑 SQL、原地清洗数据、看血缘更新。

5场景五：混合检索 + 重排 + GraphRAG

对比检索模式；让 GraphRAG 回答实体关系类问题。

HMAC 审计轨迹

上述每个写操作（摄入、清洗、脱敏策略）都被 HMAC-SHA256 审计轨迹捕获——用 GET /audit/query 配合 event_type 或 dataset_name 过滤，即可事后还原任意工作流。
