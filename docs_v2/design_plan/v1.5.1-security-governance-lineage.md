## Phase 1: Gravitino Authentication Propagation (P0 — Critical)

**Problem:** All Gravitino REST calls (`GravitinoBridge`, `GravitinoRBACBridge`, `LineageStore._notify_gravitino_version`, `gravitino.py` router) use bare `urlopen` with zero authentication headers. In production, anyone with network access to Gravitino can modify metadata.

**Article benchmark:** Gravitino supports OAuth2 / Kerberos / Simple / extensible plugins. Enterprise deployments require authenticated REST calls.

### Implementation Plan

#### 1.1 Create `GravitinoAuthProvider` Protocol

**File:** `arrow_lake/catalog/gravitino_auth.py` (new)

```python
class GravitinoAuthProvider(Protocol):
    """Protocol for injecting authentication headers into Gravitino REST calls."""

    def auth_headers(self) -> dict[str, str]:
        """Return headers to add to every Gravitino REST request."""
        ...

    def authenticate(self, request: Request) -> Request:
        """Mutate request to include auth headers. Return the modified request."""
        ...
```

#### 1.2 Implement Provider Classes

```python
class SimpleAuthProvider(GravityAuthProvider):
    """Simple auth: X-Gravitino-Authorization header with user info."""
    def __init__(self, user: str): ...
    def auth_headers(self) -> dict[str, str]:
        return {"X-Gravitino-Authorization": f"Simple {base64(user)}"}

class OAuth2AuthProvider(GravityAuthProvider):
    """OAuth2: Bearer token from configured token endpoint."""
    def __init__(self, token_url: str, client_id: str, client_secret: str): ...
    def auth_headers(self) -> dict[str, str]:
        return {"Authorization": f"Bearer {self._get_token()}"}

class KerberosAuthProvider(GravityAuthProvider):
    """Kerberos: Negotiate SPNEGO token."""
    def __init__(self, principal: str, keytab: str): ...
    def auth_headers(self) -> dict[str, str]:
        return {"Authorization": f"Negotiate {self._get_spnego_token()}"}
```

#### 1.3 Wire into Existing Callers

Modify these files to accept and use `GravitinoAuthProvider`:

| File | Current | Change |
|------|---------|--------|
| `catalog/gravitino_bridge.py` | `urlopen(req)` | `urlopen(provider.authenticate(req))` |
| `api/routers/gravitino.py` | `_gravitino_get()` bare urlopen | Use provider from `app.state.gravitino_auth_provider` |
| `catalog/lineage.py:144-215` | `_notify_gravitino_version` bare urlopen | Use provider |
| `api/rbac.py` `GravitinoRBACBridge` | Bare urlopen | Use provider |

## Phase 2: RBAC Inheritance + Deny-First (P1)

**Problem:** Current RBAC is flat — every dataset ACL is independent, no inheritance from Schema level, no explicit Deny override. The article emphasizes "继承赋权、Deny 兜底" as essential for enterprise governance.

### Implementation Plan

#### 2.1 Schema-Level ACL Inheritance

**File:** `arrow_lake/api/rbac.py`

Current `PermissionChecker`:

```python
def check_dataset_access(self, user_role, dataset_name, action):
    # Only checks per-dataset ACL
    acl = self._dataset_acls.get(dataset_name)
```

Enhanced:

```python
def check_dataset_access(self, user_role, dataset_name, action):
    # 1. Check explicit Deny first (Deny-First rule)
    if self._is_denied(dataset_name, action):
        raise HTTPException(403, detail="Access explicitly denied")

    # 2. Check per-dataset ACL
    acl = self._dataset_acls.get(dataset_name)
    if acl and action in acl.allowed_actions:
        return True

    # 3. Check Schema-level inherited ACL
    schema = self._get_schema_for_dataset(dataset_name)
    if schema:
        schema_acl = self._schema_acls.get(schema)
        if schema_acl and action in schema_acl.allowed_actions:
            return True

    # 4. Fall back to role-based default
    ...
```

#### 2.2 Add `denied_actions` to `DatasetACL`

**File:** `arrow_lake/api/rbac.py`

### 3.2 Statistics-Driven Auto Compaction

**File:** `arrow_lake/ingest/maintenance_scheduler.py` (existing — already implemented)

```python
class CompactionScheduler:
    """Auto-trigger compaction based on Gravitino statistics."""

    def __init__(self, config, stats_collector, storage):
        self._thresholds = CompactionThresholds(
            max_fragment_files=50,    # compact if >50 fragments
            max_fragment_size_mb=10,  # compact if avg fragment <10MB
            min_versions_to_compact=5, # compact if >5 old versions
        )

    def check_and_compact(self):
        """Scan all datasets, compact those exceeding thresholds."""
        for dataset in self._list_datasets():
            stats = self._stats_collector.get_stats(dataset)
            if self._needs_compaction(stats):
                self._compact(dataset, stats)

    def _needs_compaction(self, stats: DatasetStats) -> bool:
        return (
            stats.fragment_count > self._thresholds.max_fragment_files
            or stats.avg_fragment_size_mb < self._thresholds.max_fragment_size_mb
        )
```

**Wiring:** Start as background thread in `server.py` lifespan (similar to `RetentionEnforcer`).

**Acceptance Criteria:**
- [x] Background thread runs on configurable interval (default: 1 hour)
- [x] Compacts datasets exceeding `compaction_fragment_threshold`
- [x] Logs compaction results with before/after fragment counts
- [x] Version cleanup with configurable retention days
- [x] Prometheus metrics for compaction runs and duration
- [x] Configurable thresholds via `StorageConfig`

### 4.1 Auto Lineage Capture (L2 — Highest ROI)

**Problem:** Lineage events require manual `lineage_record_event()` calls. Core pipelines (ingest, query, RAG, export) don't automatically capture lineage.

**File:** `arrow_lake/catalog/lineage_hooks.py` (new)

```python
def auto_record_ingest(dataset_name, operation, *, source_files=None, ...):
    """Called by Ingestor after successful ingest."""
    create_lineage_event(
        dataset_name, operation,
        source_datasets=_extract_source_datasets(source_files),
        transform_type="ingest",
        actor="system:ingest-pipeline",
    )

def auto_record_query(dataset_name, sql, result_rows, ...):
    """Called by OlapSearchBridge after successful query."""
    create_lineage_event(
        dataset_name, "query",
        transform_type="olap-query",
        metadata={"sql_preview": sql[:200], "result_rows": result_rows},
    )

def auto_record_rag(dataset_name, question, retrieved_chunks, ...):
    """Called by RAG pipeline after successful retrieval."""
    source_datasets = list({chunk["dataset"] for chunk in retrieved_chunks})
    create_lineage_event(
        dataset_name, "rag-query",
        source_datasets=source_datasets,
        transform_type="rag-retrieval",
        metadata={"question_preview": question[:100]},
    )

def auto_record_export(dataset_name, output_path, ...):
    """Called by export pipeline after successful export."""
    create_lineage_event(
        dataset_name, "export",
        transform_type="file-export",
        metadata={"output_path": output_path},
    )

def auto_record_federated(catalog_tables, join_sql, ...):
    """Called by FederatedQueryEngine after cross-catalog query."""
    source_datasets = [fqn for fqn, _ in catalog_tables]
    create_lineage_event(
        "_federated_result", "federated-join",
        source_datasets=source_datasets,
        transform_type="cross-catalog-sql",
        metadata={"join_sql_preview": join_sql[:200]},
    )
```

- `arrow_lake/query/olap.py` — after successful query

- `arrow_lake/ingest/_storage_crud.py` — after export

**Acceptance Criteria:**

```python
def _to_mermaid(graph: dict) -> PlainTextResponse:
    lines = ["graph LR"]
    for edge in graph["edges"]:
        lines.append(f'    {edge["from"]} -->|{edge["operation"]}| {edge["to"]}')
    return PlainTextResponse("\n".join(lines), media_type="text/plain")

def _to_dot(graph: dict) -> PlainTextResponse:
    lines = ["digraph lineage {", '  rankdir=LR;']
    for edge in graph["edges"]:
        lines.append(f'  "{edge["from"]}" -> "{edge["to"]}" [label="{edge["operation"]}"];')
    lines.append("}")
    return PlainTextResponse("\n".join(lines), media_type="text/vnd.graphviz")
```

## Risk Assessment

| Risk | Mitigation |
|------|-----------|
| Gravitino auth change breaks existing deployments | Default to no-auth (backward compatible), WARNING log when unauthenticated |
| RBAC inheritance changes access control behavior | Feature flag: `enable_schema_acl_inheritance`, default false in v1.5.1, true in v1.6.0 |
| Auto lineage capture impacts pipeline performance | All hooks are fire-and-forget (try/except, never block main path), async where possible |
| Column lineage parsing incomplete | Best-effort: fall back to table-level lineage when SQL is too complex to parse |
| Predicate pushdown breaks complex queries | Only pushdown simple equality/range filters; complex expressions stay in DuckDB |
