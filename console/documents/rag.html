RAG 问答管线

多检索策略（fts / vector / hybrid）、流式输出、多轮对话、Reranker 重排序与 faithfulness 防幻觉校验——返回结构化 RAGResponse（answer / citations / 指标）。

难度 · 中高级耗时 · 25 分钟前置 · 向量索引 + LLM

Lake.rag_query() 完整执行「检索 → 增强（拼上下文）→ 生成」。检索依赖目标数据集已建向量索引；未建则回退纯 FTS，无可用策略时抛 RAGError。

5踩坑提示

向量索引必须先建

rag_query 无向量索引时回退 FTS，若也无则抛 RAGError；列名必须 text_embedding（向量）/ text_content（文本），否则管线不认。

混合检索需 ≥256 行

IVF_PQ 硬限制——小数据集自动跳过建 IVF，hybrid 降级走 brute-force vector。

最优 QA 配置

抽取 / 查询改写用 extract_llm=qwen-turbo（快、支持 json_schema），生成用 qa_llm=qwen-plus@16384（质量最优）；Anthropic 提取 system 到顶层字段，Ollama 对 qwen3.x 自动禁用 extended thinking。

离线与会话

reranker 模型从 HF_HOME 加载，离线 / 气隙需预下载；加载失败透明回退 noop（不硬失败）；流式响应的 verification/citations 在末帧。会话历史持久化需配 rag.history_dataset（默认 _rag_sessions）。
