OLAP 分析

DuckDB 零拷贝 Arrow 集成驱动的高性能分析：GROUP BY 聚合、窗口函数、多表 JOIN、DuckLake 物化视图与 Daft DataFrame——覆盖查询、导出与引擎调优全链路。

难度 · 中级 耗时 · 15 分钟 前置 · Lance 数据集 + DuckDB

Arrow Lake 通过 DuckDB 零拷贝 Arrow 集成提供高性能 OLAP 分析能力，支持 GROUP BY 聚合、窗口函数、JOIN 以及物化视图。本章串起「基础查询 → 窗口函数 → JOIN → 物化视图 → Daft DataFrame → 导出 → 配置 → 错误处理」全链路。

前置准备

确保已安装依赖 pip install arrow-lake[olap]，并有一个已写入数据的 Lance 数据集。

1基础 SQL 查询

Lake.olap_query() 在 Lance 数据集上执行只读 SQL（SELECT 语句），返回 OlapQueryResult，其中 .table 是 PyArrow Table，可直接转 Pandas。

通过 max_rows 参数限制返回行数，防止内存溢出：

注意

Lake.sql_query() 是更低层的替代方法，直接返回 pa.Table（不包装为 OlapQueryResult）；Lake.query() 返回 MetadataQueryResult，用于元数据查询。需要行/列计数和元数据时使用 olap_query()，只需原始 Arrow 表时使用 sql_query()。

2窗口函数

DuckDB 支持完整的窗口函数语法，适合排名、累计求和、环比等场景。

常见窗口函数速查：

函数用途示例
ROW_NUMBER()行编号（不重复）ROW_NUMBER() OVER (ORDER BY amount DESC)
RANK()排名（并列跳号）RANK() OVER (ORDER BY score DESC)
SUM() OVER累计求和SUM(amount) OVER (ORDER BY date)
AVG() OVER移动平均AVG(amount) OVER (ORDER BY date ROWS BETWEEN 2 PRECEDING AND CURRENT ROW)
LAG() / LEAD()前/后值偏移LAG(amount, 1) OVER (ORDER BY date)

8导出数据

Lake.export() 将数据集导出为 Parquet 或 CSV 文件，支持列选择、版本指定和压缩配置。返回 ExportResult。

参数说明：

参数类型说明
dataset_namestr源数据集名称
output_pathstr输出文件路径（.parquet 或 .csv）
formatstr | None导出格式，None 自动从路径后缀推断
columnslist[str] | None只导出指定列
versionint | None数据集版本号，None 使用最新版
compressionstr | NoneParquet 压缩编码（snappy, gzip, zstd 等）
overwritebool是否覆盖已有文件（默认 False）
异步与多目标导出（REST）

通过 POST /api/v1/datasets/{name}/export 异步导出大数据集，立即返回 202 + task_id，随后用 GET /{name}/export/{task_id}/status 轮询状态、GET /{name}/export/{task_id}/download 下载结果。请求体 ExportRequest 必填 output_path（相对路径，禁止 .. / 绝对路径 / 空字节）。

POST /api/v1/datasets/{name}/export-to（同步）通过 Daft 将数据集导出到外部目标，支持 parquet / csv / json / iceberg / clickhouse 五种格式，请求体 target_uri + format 必填。

9OLAP 配置参考

通过 ArrowLakeConfig.olap 精调分析引擎行为：

配置项默认值说明
max_result_rows100,000查询最大返回行数
enable_predicate_pushdownTrue是否将谓词下推到 Lance
enable_joinTrue是否允许 JOIN 查询
enable_streamingTrue使用 RecordBatchReader 流式读取
lance_scan_mode"auto"Lance 扫描模式
max_query_memory_mb512单查询内存上限（MB）
max_concurrent_queries4最大并发查询数
query_timeout_seconds300查询超时时间（秒）
ducklake_enabledFalse是否启用 DuckLake 物化视图
ducklake_ttl_days7物化视图默认 TTL（天）
生产必配（v1.9.6）

RAG/OLAP 混合路径若遇 DuckDB lance vector stream Rust panic（502 + worker died），将 lance_scan_mode 设为 "pyarrow_fallback" 绕开 DuckDB native lance scanner。物化视图（ducklake_enabled）默认关闭，启用时配套定时 cleanup_materialized() 控制存储增长。
