① 接入层 · ENTRY

一条提问，三个入口任选

同一份 Lake facade，对外是 Python SDK、REST(106 routes)、CLI 三种面孔。点右侧标签切换——请求体完全等价。

</> 技术细节
Lake facade · 9 mixin（v1.6.0）：摄入/检索/OLAP/RAG/KG/质量/治理/管理/任务，统一门面。REST 经 FastAPI 覆盖 106 端点，CLI 16 命令组。三入口共享同一套 Pydantic 模型，行为一致。
v1.6.0 facade+9mixin

提问先经 Qwen3 嵌入成 1024 维向量。看右图——query 落入向量空间，候选点云向它聚拢。每一颗点，是一段被切碎的文档。

</> 技术细节
IVF_PQ 索引（v1.7.1 lancedb 0.33 + pylance 7.0）：nprobes=12 探测最近簇，PQ 量化压缩内存 8×。Reranker（v1.8.0）在 hybrid bridge 内自动重排，无需 per-query 开关。标量索引全量补齐，where 过滤下推 Lance 层。
v1.7.1 标量索引v1.8.0 Reranker
② 能力层 · 检索漏斗

从 9.4M 到 10，每一步都在剪枝

向量检索不是一次比较，是一串漏斗。看候选如何在 IVF 探测、PQ 量化、rerank、top_k 里逐层缩减——精度与速度的权衡可视化。

</> 技术细节
全量 9,432,881 行 → IVF nprobes 命中 12 簇共 ~141k 行 → PQ 近似排序取前 2,000 → Reranker 精排 → top_k=10。谓词下推让 where 在 Lance 层先过滤，零拷贝读取只物化匹配行。
v1.7.1 pylance7.0
② 能力层 · 多模态

不止文字——图、音频、视频一锅找

CLIP 把图像和文本嵌入同一空间。用一句话搜论文里的图表、用一帧搜视频片段、用波形搜音频——相似度热力告诉你多像。

</> 技术细节
CLIP 嵌入（v1.8.0 #6）：image 与 text 共享 512 维空间，跨模态检索走 vector_column='clip'。多模态卡片墙复用 search/vector 接口，只是 vector_column 不同。
v1.8.0 CLIP
②→⑤ KG 旁路 · GRAPHRAG

不只找相似——懂关系

知识图谱是五层里唯一的旁路：能力层直达持久化。GraphRAG 拉出 attention 相关子图，论文→方法→数据集的关系网比纯文本更结构化。

</> 技术细节
per-dataset 分图（v1.8.6）：每个 dataset 独立图 kg_{dataset}，删数据集即清图零残留。kg_papers 与 kg_finance 物理隔离。hyper-extract（v1.7.0）+ doc_type 三层路由自动建图。8 traverser 全 REST 暴露，per-dataset ACL 防 IDOR。
v1.7.0 hyper-extractv1.8.6 分图+ACL
③ 计算层 · COMPUTE

URL 进，结构化出

Daft 分布式 DataFrame 跑批推理：下载→解码→CLIP 嵌入→质量评分→落盘，全流水线。Ray 集群横向扩展，单机也能回退本地。

</> 技术细节
Daft AI（v1.8.0 #13）：DataFrame 原生多模态列（image/audio/video），daft.read_parquet → .decode_image() → .ai.embed() 链式。Ray 不可用时 set_runner 本地，优雅降级。
v1.8.0 Daft AI
④ 引擎层 · ENGINES

SQL 一句话，9.4M 行零拷贝算完

DuckDB 直接读 Lance 列式，不导入、不复制。看查询计划树——每个算子的行数与耗时，谓词在 Lance 层下推，只物化匹配行。

</> 技术细节
DuckDB 1.5.2（v1.7.1）+ SQL-PGQ（v1.8.0 #10）：图模式查询直接在 DuckDB 里跑。DuckLake 物化视图（v1.8.0 #9）跨存储 JOIN。Arrow RecordBatch 流式返回，超内存数据集也能跑。
v1.7.1 DuckDB1.5.2v1.8.0 SQL-PGQ
⑤ 持久化 · PERSISTENCE

每次写入都是一次快照——时光可倒流

Lance 列式天然多版本。拖动右侧 timeline，回到任意版本看快照，diff 两个版本看哪些行变了。血缘 DAG 追踪每个表的来龙去脉。

</> 技术细节
Lance branches（v1.8.0 #1）：表级分支与标签，git 风格版本管理。行级 lineage（v1.8.0 #3）+ catalog/lineage（v1.6.0）跨数据集 DAG。MinIO/S3 存原始，Redis 存会话，HugeGraph 存 kg_{ds}。
