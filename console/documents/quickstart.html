快速入门

5 分钟从零创建数据湖、写入数据、执行 SQL 查询并导出结果。理解 Lake facade、数据集与版本模型。

难度 · 入门 耗时 · 5 分钟 依赖 · 仅 Python 3.11+

Arrow Lake 把存储 / 检索 / 分析 / 智能化收敛到一个 Lake facade 之后。本章用一个最小可运行示例串起「创建数据集 → 追加 → 查询 → 导出」全链路，并给出 CLI 与生产配置入口。

1核心概念

Lake facade

主入口 Lake(base_uri=...)，封装数据集创建、追加、查询、导出、目录等全部操作。生产环境推荐 Lake.from_yaml("config.yaml") 统一管理参数。

dataset（数据集）

一个 Lance 列式 dataset，等价于一张表；SQL 中的表名必须与 dataset 名称一致。每次写入自增一个 version（Lance 原生版本控制）。base_uri 是存储根，支持本地路径或 s3://bucket/prefix（MinIO / AWS S3）。

query vs olap_query

lake.query 单表 SQL 过滤；lake.olap_query 支持 GROUP BY、窗口函数、JOIN 等聚合分析。

注意

SQL 中的表名必须与 dataset 名称一致；append_dataset 的 schema 必须与原表完全匹配；export 的父目录（如 output/）必须事先存在。

推荐

配置
