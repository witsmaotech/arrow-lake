01 · 时代变了

你的数据，早就不是表格了。

十年前

数据 = 表格

行、列、主键、SQL —— PostgreSQL 加一个 Redis，撑起绝大多数业务。

现在

数据 = 多模态

PDF 合同 · 产品图片 · 客服录音 · 1536 维嵌入向量 · 实体关系图谱

没有行和列，塞不进关系模型，跑不了标准 SQL。

传统数据栈从第一天起就不是为这些东西设计的 ——
这不是某家厂商的锅，是整个范式的滞后。

02 · 每个诉求催生一个系统

没有任何一个选型是错的。

你是被真实的业务需求，一步一步推到这里的。

08 · 安全不是事后加的

从第一行代码开始。

RBAC 三级

VIEWER / EDITOR / ADMIN，作用在 40+ 端点

双模认证

API Key + JWT (HS256/RS256)，Redis 黑名单 + TTL

注入防御

Gremlin / SQL / 路径穿越 / FQN —— 四向参数化

审计链

HMAC-SHA256 防篡改，操作可追溯、不可抵赖

传输安全

TLS 终止 + CSP + HSTS + X-Frame-Options

Bandit 扫描

0 HIGH

CI 的硬门槛
